= ONTAP 업그레이드 후 검증 워크플로
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ONTAP를 업그레이드한 후 클러스터 준비 상태를 확인하기 위해 수행해야 하는 몇 가지 작업이 있습니다.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["1개"] 클러스터를 확인합니다.
[role="quick-margin-para"]
ONTAP를 업그레이드한 후 link:task_verify_cluster_after_upgrade.html["클러스터 버전, 클러스터 상태 및 스토리지 상태를 확인합니다."]해야 합니다. MetroCluster FC 구성을 사용하는 경우 클러스터에서 자동 비계획 전환이 활성화되어 있는지도 확인해야 합니다.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["2개"] 모든 LIF가 홈 포트에 있는지 확인하십시오.
[role="quick-margin-para"]
재부팅 중에 일부 LIF가 할당된 페일오버 포트로 마이그레이션되었을 수 있습니다. 클러스터를 업그레이드한 후에는 반드시 link:task_enabling_and_reverting_lifs_to_home_ports_post_upgrade.html["홈 포트에 없는 LIF를 활성화하고 되돌립니다."].

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["세 가지"] 클러스터에 특정한 특별 고려 사항을 확인하십시오.
[role="quick-margin-para"]
클러스터에 특정 구성이 있는 경우 link:concept_special_configurations_post_checks.html["업그레이드 후 추가 단계를 수행합니다"]이(가) 필요할 수 있습니다.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-4.png["네"] 디스크 적격성 패키지(DQP)를 업데이트하십시오.
[role="quick-margin-para"]
DQP는 ONTAP 업그레이드의 일부로 업데이트되지 않습니다. 업그레이드 후 link:concept_when_you_need_to_update_the_disk_qualification_package.html["DQP를 업데이트합니다"]해야 합니다.

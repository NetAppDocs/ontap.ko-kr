= ONTAP FabricPool 미러를 탈거하십시오
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
더 이상 오브젝트 저장소를 복제할 필요가 없는 경우 FabricPool 미러를 제거할 수 있습니다.

.시작하기 전에
운영 오브젝트 저장소가 작동 중이어야 하며, 그렇지 않으면 명령이 실패합니다.


WARNING: 이 작업은 오브젝트 저장소 컨테이너의 모든 오브젝트를 영구적으로 삭제하며 되돌릴 수 없습니다. 오브젝트 삭제는 미러링 해제 작업이 완료된 후에도 백그라운드에서 계속 진행됩니다. 백그라운드 삭제 프로세스가 완료될 때까지 컨테이너를 재사용하거나 다른 용도로 사용하지 마십시오.

.단계
. 'storage aggregate object-store unmirror-aggregate' 명령을 사용하여 FabricPool에서 오브젝트 저장소 미러를 제거합니다.
+
[listing]
----
cluster1::> storage aggregate object-store unmirror -aggregate aggr1
----

= ONTAP 9.20.1에서 이전 버전으로 되돌리기 전에 SHA-512 SNMPv3 사용자를 제거하십시오.
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ONTAP 9.20.1부터는 SHA-512 인증을 사용하는 SNMPv3 사용자를 생성할 수 있습니다. 9.20.1 이전의 ONTAP 버전은 SHA-512 인증을 지원하지 않으므로, SHA-512 인증을 사용하는 SNMPv3 사용자가 있는 경우 ONTAP에서 되돌리기를 차단합니다. 되돌리기 전에 이러한 사용자를 삭제하고 지원되는 인증 프로토콜을 사용하여 다시 생성하십시오.

.단계
. SHA-512 인증을 사용하는 SNMPv3 사용자를 표시합니다:
+
[source, cli]
----
security snmpusers -authmethod usm -authprotocol sha512
----
. 각 SHA-512 사용자를 삭제합니다:
+
[source, cli]
----
security login delete -vserver <vserver_name> -user-or-group-name <user_name> -application snmp -authentication-method usm
----
. 사용자가 여전히 필요한 경우,  `sha` 또는  `sha2-256` 등 지원되는 인증 프로토콜을 사용하여 사용자를 다시 생성하십시오:
+
[source, cli]
----
security login create -vserver <vserver_name> -user-or-group-name <user_name> -application snmp -authentication-method usm
----
+
사용자가 스위치를 모니터링하는 경우 스위치의 IP 주소와 함께  `-remote-switch-ipaddress` 매개변수를 포함하십시오:

+
[source, cli]
----
security login create -user-or-group-name <user_name> -application snmp -authentication-method usm -remote-switch-ipaddress <switch_ip_address>
----
+
link:../networking/configure_snmpv3_users_in_a_cluster.html["SNMPv3 사용자 구성"]에 대해 자세히 알아보십시오.

. 삭제된 SHA-512 사용자를 모니터링에 사용하던 이더넷 스위치가 있는 경우, 각 스위치가 다시 생성된 사용자를 사용하도록 업데이트하십시오:
+
[source, cli]
----
system switch ethernet modify -device <switch_name> -snmp-version SNMPv3 -community-or-username <snmp_user_name>
----
+
link:https://docs.netapp.com/us-en/ontap-cli/system-switch-ethernet-modify.html["ONTAP 명령 참조입니다"^]에서  `system switch ethernet modify`에 대해 자세히 알아보십시오.

+
이더넷 스위치 구성 방법을 포함하여 이더넷 스위치 상태 모니터링(CSHM)용 SNMPv3에 대한 자세한 내용은 link:https://docs.netapp.com/us-en/ontap-systems-switches/switch-cshm/config-snmpv3.html["이더넷 스위치 상태 모니터링을 위한 SNMPv3 구성"^]을(를) 참조하십시오.

= ONTAP 9.20.1로 되돌리기 위해 영구 예약 등록을 제거합니다.
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ONTAP 9.20.1 이전 버전은 LUN당 최대 182개의 SCSI-3 영구 예약 등록을 지원합니다. ONTAP 9.20.1부터 이 제한은 256개로 증가합니다. 어떤 LUN이라도 과거에 182개 등록을 초과한 적이 있다면, ONTAP은 현재 등록 개수와 관계없이 되돌리기를 차단합니다. 9.20.1에서 9.19.1로 되돌리기 전에 영향을 받는 LUN에서 영구 예약 등록을 확인하고 제거하십시오.


IMPORTANT: 클러스터 환경에서 영구 예약 등록을 제거하려면 호스트 측 재구성이 필요할 수 있습니다. 호스트 운영 체제 및 클러스터링 소프트웨어에 따라 클러스터 리소스를 오프라인으로 전환하고, 클러스터 관리에서 영향을 받는 LUN을 제거한 다음, 복원 후 클러스터 액세스를 다시 설정해야 할 수 있습니다. 복원하기 전에 클러스터링 솔루션 설명서를 검토하고 테스트 환경에서 복구 워크플로를 검증하십시오.

.단계
. 어떤 LUN이 과거에 영구 예약 등록 수 182개를 초과했는지 확인하십시오:
+
[source, cli]
----
lun show -field persistent-reservation-scale-tier
----
+
persistent-reservation-scale-tier 필드의 값이 182를 초과하면 LUN이 추가 영구 예약 메타데이터를 할당했음을 나타냅니다. 이 경우 현재 등록 횟수와 관계없이 복원이 차단됩니다.

. 영향을 받는 각 LUN에 대해 현재 활성 등록 수를 표시합니다:
+
[source, cli]
----
lun persistent-reservation show -vserver <vserver_name> -path <lun_path>
----
. 영향을 받는 모든 LUN에서 영구 예약 등록을 제거합니다.
+
되돌리기 사전 검사를 실행합니다. 이 조건이 감지되면 사전 검사 출력에 필요한 특정 정리 명령이 포함됩니다.

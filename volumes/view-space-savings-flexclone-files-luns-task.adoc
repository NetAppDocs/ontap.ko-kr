= FlexClone 파일 및 FlexClone LUN을 사용하여 ONTAP 공간 절약 확인
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
FlexClone 파일 및 FlexClone LUN이 포함된 볼륨에서 블록 공유를 통해 절약된 디스크 공간의 비율을 볼 수 있습니다. 이 작업은 용량 계획의 일부로 수행할 수 있습니다.

.단계
. FlexClone 파일 및 FlexClone LUN으로 인한 공간 절약 효과를 확인하십시오:
+
[source, cli]
----
volume show -volume <vol_name> -vserver <SVM> -fields used, sis-space-saved, dedupe-space-saved, compression-space-saved
----
+
[NOTE]
====
중복 제거 기능이 활성화된 FlexVol 볼륨에서 이 명령을 실행하면 중복 제거 및 FlexClone 파일과 LUN을 통해 절약된 공간을 확인할 수 있습니다.

====

= 대용량 디렉터리 최대 크기에 대한 ONTAP 지원을 활성화합니다.
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ONTAP 9.20.1부터는 볼륨을 생성하거나 기존 볼륨을 수정할 때 더 큰 최대 디렉터리 크기에 대한 지원을 활성화하고 구성할 수 있습니다. 이를 통해 최대 4GB의 디렉터리 크기를 기준으로 디렉터리에 최대 약 2,500만 개의 파일, 폴더 및 기타 항목을 포함할 수 있습니다.

[CAUTION]
====
최대 디렉터리 크기를 늘린 후에는 해당 디렉터리를 볼륨에 다시 생성하지 않고는 크기를 줄일 수 없습니다.

====
.시작하기 전에
더 큰 최대 디렉터리 크기를 지원하도록 볼륨을 생성하거나 수정하기 전에 클러스터 또는 SVM 관리자인지 확인하십시오.



[[create-a-new-volume]]
== 새 볼륨을 생성합니다

새 볼륨을 생성할 때 최대 디렉터리 크기를 더 크게 설정할 수 있습니다.

.단계
. 더 큰 디렉터리 최대 크기 지원이 활성화된 볼륨을 생성합니다:
+
[source, cli]
----
volume create -vserver <svm_name> -volume <volume_name> -aggregate <aggr_name> -is-dir-index-transfer-enabled true
----
+
.예
[listing]
----
volume create -vserver vs1 -volume big_dir1 -aggregate aggr1 -is-dir-index-transfer-enabled true
----
. 최대 디렉터리 크기를 최대 4GB까지 늘리십시오:
+
[source, cli]
----
volume modify -vserver <svm_name> -volume <volume_name> -maxdir-size <dir_size>
----
+
.예
[listing]
----
volume modify -vserver vs1 -volume big_dir1 -maxdir-size 4GB
----




[[modify-an-existing-volume]]
== 기존 볼륨을 수정합니다

기존 볼륨을 수정하여 최대 디렉토리 크기를 더 크게 설정할 수 있습니다.

.단계
. 기존 볼륨에서 더 큰 디렉토리 최대 크기에 대한 지원을 활성화합니다:
+
[source, cli]
----
volume modify -vserver <svm_name> -volume <volume_name> -is-dir-index-transfer-enabled true
----
+
.예
[listing]
----
volume modify -vserver vs2 -volume data_vol -is-dir-index-transfer-enabled true
----
. 디렉토리 최대 크기를 4GB까지 늘리십시오:
+
[source, cli]
----
volume modify -vserver <svm_name> -volume <volume_name> -maxdir-size <dir_size>
----
+
.예
[listing]
----
volume modify -vserver vs2 -volume data_vol -maxdir-size 4GB
----

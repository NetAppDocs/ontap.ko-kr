= ONTAP LIF의 포트 유형 호환성
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
LIFs는 다양한 포트 유형을 지원하기 위해 서로 다른 특성을 가질 수 있습니다. LIFs는 IPspace 내의 물리적 포트 또는 논리적 포트에 호스팅될 수 있습니다. 각 포트는 하나의 IPspace에만 연결됩니다.


NOTE: 인터클러스터 및 관리 LIF가 동일한 서브넷에 구성된 경우 관리 트래픽이 외부 방화벽에 의해 차단될 수 있으며 AutoSupport 및 NTP 연결이 실패할 수 있습니다. 'network interface modify -vserver_vserver name_-lif_인터클러스터 LIF_-status-admin up|down' 명령을 실행하여 인터클러스터 LIF를 전환하여 시스템을 복구할 수 있습니다. 그러나 이 문제를 방지하려면 인터클러스터 LIF 및 관리 LIF를 다른 서브넷에 설정해야 합니다.

다음 표는 LIF 유형, 호환 포트 유형 및 장애 조치 또는 마이그레이션 동작을 요약합니다.

[cols="30,70"]
|===


| LIF | 설명 


| 클러스터 LIF  a| 
클러스터 내 노드 간에 클러스터 내부 트래픽을 전달하는 데 사용되는 LIF입니다.

* 클러스터 LIF는 항상 클러스터 포트에 생성해야 합니다.
* 클러스터 LIF는 동일 노드 내의 클러스터 포트 간에 페일오버될 수 있지만, 원격 노드로 마이그레이션하거나 페일오버할 수는 없습니다. 새 노드가 클러스터에 참여하면 IP 주소가 자동으로 생성됩니다. 하지만 클러스터 LIF에 IP 주소를 수동으로 할당하려면 새 IP 주소가 기존 클러스터 LIF와 동일한 서브넷 범위에 있어야 합니다.




| 클러스터 관리 LIF  a| 
클러스터 전체에 대한 단일 관리 인터페이스를 제공하는 LIF입니다.

* 클러스터 관리 LIF는 클러스터 내의 모든 노드로 페일오버할 수 있습니다. 클러스터 포트 또는 클러스터 간 포트로는 페일오버할 수 없습니다.




| 데이터 LIF  a| 
스토리지 가상 머신(SVM)과 연결되어 클라이언트와의 통신에 사용되는 LIF입니다.

* 각 SVM은 특정 IPspace와 연결됩니다. 데이터 SVM은 일반적으로 "기본" IPspace에 있지만 반드시 그런 것은 아닙니다.
* 하나의 포트에 여러 개의 데이터 LIF를 호스팅할 수 있습니다. 이러한 데이터 LIF는 클러스터 전체에서 마이그레이션 또는 장애 조치를 수행할 수 있습니다. 방화벽 정책을 mgmt로 수정하여 데이터 LIF를 SVM 관리 LIF로 사용할 수 있도록 변경할 수 있습니다.
* NIS, LDAP, Active Directory, WINS 및 DNS 서버와의 세션 설정에는 데이터 LIF가 사용됩니다.




| 인터클러스터 LIF  a| 
클러스터 간 통신, 백업 및 복제에 사용되는 LIF입니다.

* 클러스터 피어링 관계를 설정하기 전에 클러스터의 각 노드에 클러스터 간 LIF를 생성해야 합니다. 이러한 LIF는 동일한 노드의 포트로만 페일오버할 수 있습니다. 클러스터 내의 다른 노드로 마이그레이션하거나 페일오버할 수 없습니다.




| 노드 관리 LIF  a| 
클러스터 내 특정 노드를 관리하기 위한 전용 IP 주소를 제공하는 LIF입니다.

* 노드 관리 LIF는 클러스터 생성 또는 참여 시점에 생성됩니다. 이러한 LIF는 시스템 유지 관리, 예를 들어 노드가 클러스터에서 접근할 수 없게 된 경우에 사용됩니다.




| SVM 관리 LIF  a| 
SVM에 대한 관리 연결을 제공하여 해당 SVM에 대한 관리 작업(대개 443번 포트를 통해) 및 관리 관련 서비스를 가능하게 하는 LIF입니다.

* 각 SVM은 특정 IPspace와 연결됩니다.
* LIF는 페일오버 정책에 따라 다른 노드 또는 포트로 마이그레이션하거나 페일오버할 수 있습니다.
* 하나의 포트에 여러 개의 SVM 관리 LIF를 호스팅할 수 있습니다.
* SVM 관리 LIF는 멀티 테넌시(multi-tenancy) 환경에서 호스팅할 때 유용합니다.




| VIP LIF  a| 
가상 IP(VIP) LIF는 VIP 포트에서 생성된 모든 데이터 LIF입니다.

자세한 내용은 link:../networking/configure_virtual_ip_vip_lifs.html["가상 IP(VIP) LIF를 구성합니다"]을 참조하십시오.

= ONTAP 9.20.1의 새로운 기능
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ONTAP 9.20.1에서 새롭게 제공되는 기능에 대해 알아보세요.

최신 ONTAP 9 릴리스에서 알려진 문제, 제한 사항 및 업그레이드 주의 사항에 대한 자세한 내용은 를 참조하십시오 https://library.netapp.com/ecm/ecm_download_file/ECMLP2492508["ONTAP 9 릴리즈 노트"^]. 릴리스 정보에 액세스하려면 NetApp 계정으로 로그인하거나 계정을 만들어야 합니다.

* 새로운 기능 및 향상된 기능에 대해 알아봅니다 https://docs.netapp.com/us-en/ontap-metrocluster/releasenotes/mcc-new-features.html["ONTAP MetroCluster 기능"^].
* 자세히 알아보기 https://docs.netapp.com/us-en/ontap-afx/release-notes/whats-new-9201.html["NetApp AFX 스토리지 시스템을 위한 새롭고 향상된 ONTAP 소프트웨어 기능"^].
* 자세히 알아보기 https://docs.netapp.com/us-en/asa-r2/release-notes/whats-new-9201.html["NetApp ASA r2 스토리지 시스템을 위한 새롭고 향상된 ONTAP 소프트웨어 기능"^].
* 에 대해 알아보세요  https://docs.netapp.com/us-en/ontap-systems/whats-new.html["AFF, ASA 및 FAS 시스템과 지원되는 스위치에 대한 새롭고 향상된 지원"^] .
* 의 업데이트에 대해 알아봅니다 https://docs.netapp.com/us-en/ontap-automation/whats_new.html["ONTAP REST API를 참조하십시오"^].


최신 버전의 ONTAP로 업그레이드하려면 를 참조하십시오link:../upgrade/create-upgrade-plan.html["ONTAP 업그레이드를 준비합니다"].



[[data-protection]]
== 데이터 보호

[cols="30%,70%"]
|===
| 업데이트 | 설명 


 a| 
xref:../data-protection/cloud-backup-with-snapmirror-task.html[SnapMirror 클라우드의 원본 소스 볼륨으로의 제자리 복원 지원]
 a| 
SnapMirror 클라우드는 FlexVol 볼륨에 대한 제자리 복원 작업을 지원하므로 클라우드 스냅샷 복원 작업을 원래 소스 볼륨으로 직접 수행할 수 있습니다. ONTAP은 최신 공통 스냅샷을 선택하고 증분 전송을 수행하여 복원 시간을 단축합니다.



 a| 
xref:../snapmirror-active-sync/limits-reference.html[SnapMirror 활성 동기화 오브젝트 제한 증가]
 a| 
SnapMirror 액티브 싱크는 SAN 및 NAS 구성에서 HA 쌍당 지원되는 볼륨 수를 600개로 늘립니다.



 a| 
xref:../snaplock/snapshot-lock-concept.html[SnapMirror 액티브 싱크 NAS를 통한 변조 방지 스냅샷 지원]
 a| 
ONTAP은 SnapMirror 액티브 싱크 NAS FlexVol 볼륨에 대한 변조 방지 스냅샷 지원을 추가합니다. 이 개선 사항을 통해 고객은 SnapMirror 액티브 싱크 NAS 가용성과 변경 불가능한 스냅샷 보호 기능을 결합할 수 있습니다.



 a| 
xref:../data-protection/modify-svm-dr-dest-vol-capacity-task.html[향상된 SVM 재해 복구]
 a| 
ONTAP은 표준 관리자 권한 볼륨 수정 워크플로를 사용하여 SVM-DR 대상 볼륨에서 선택한 볼륨 수정 속성을 허용함으로써 SVM 재해 복구를 향상시키고, 지원팀의 지원이 필요한 절차에 대한 필요성을 줄여줍니다.

ONTAP은 또한 FlexGroup 구성 요소에 선택적 SVM-DR 빠른 재동기화 지원을 확장하여 대규모 FlexGroup 기반 SVM이 재해 복구 연습, 재동기화 또는 플립 재동기화 워크플로 후 더 빠르게 보호 상태로 복귀할 수 있도록 지원합니다.

자세한 내용은 xref:../data-protection/resync-svm-destination-task.html[ONTAP SnapMirror 대상 SVM에서 데이터를 다시 동기화합니다] 참조하십시오.



 a| 
xref:../data-protection/configure-backend-fc-replication.html[FC를 통한 SnapMirror 복제에 대한 백엔드 지원]
 a| 
기존 Fibre Channel(FC) 패브릭을 통해 백엔드 SnapMirror 비동기 복제 및 SnapVault용 SnapLock을 구성할 수 있습니다.

이를 통해 복제 트래픽이 기존 SAN 인프라 내에서만 이동할 수 있습니다. ONTAP 9.20.1 이전 버전에서는 이러한 복제 관계에 대한 트래픽이 클러스터 간 IP 네트워크를 통해서만 전송되었습니다.



 a| 
xref:../consistency-groups/protect-task.html[비 SnapLock 소스 일관성 그룹에서 SnapLock for SnapVault 대상 일관성 그룹으로의 복제]
 a| 
비 SnapLock 소스 일관성 그룹에서 SnapVault용 SnapLock 대상 일관성 그룹으로 복제할 수 있습니다. SnapVault용 SnapLock은 복제된 일관성 그룹을 실수 또는 악의적인 삭제로부터 보호합니다.



 a| 
xref:../san-admin/fc-sp-3-security-support.html[Broadcom 보안 HBA를 사용한 FC-SP-3 인증 및 암호화]
 a| 
ONTAP은 AFF 및 FAS 시스템을 갖춘 Broadcom 보안 HBA에서 Fibre Channel Security Protocol 3(FC-SP-3) 인증 및 암호화를 지원합니다. FC-SP-3 지원을 통해 하드웨어 수준의 엔드 투 엔드 암호화 및 디바이스 인증을 활성화하여 T11 Fibre Channel 보안 표준을 준수하는 동시에 FC 및 NVMe/FC SAN 호스트와 ONTAP 스토리지 시스템 간에 전송되는 데이터를 보호할 수 있습니다.

암호화가 오프로드되므로 스토리지 시스템에 성능 영향이 없습니다.

[[fpolicy-enhancements]]
== FPolicy 개선 사항

[cols="30%,70%"]
|===
| 업데이트 | 설명 


 a| 
xref:../nas-audit/supported-file-operation-filter-fpolicy-nfsv4-concept.html[NFS 4.2에 대한 FPolicy 지원]
 a| 
FPolicy는 파일 액세스 모니터링을 NFSv4.2로 확장하여 최신 NFS 프로토콜 버전을 사용하는 환경에 대한 감사, 규정 준수 및 사이버 복원력 워크플로우를 지원합니다. FPolicy는 확장 속성 쓰기(SETXATTR, REMOVEXATTR) 및 SETATTR/GETATTR을 통한 보안 레이블 변경 등 NFSv4.2 파일 작업에 대한 알림을 생성합니다. NFSv4.2 알림에는 protobuf 형식으로 구성된 외부 엔진이 필요합니다.



 a| 
xref:../nas-audit/supported-file-operation-filter-fpolicy-s3.html[Fpolicy의 S3 오브젝트 스토리지 지원]
 a| 
FPolicy는 S3 오브젝트 워크플로우에 대한 보안 모니터링을 제공합니다. 이는 파일 및 오브젝트 스토리지를 위한 통합 FPolicy 프레임워크를 제공하여 하이브리드 데이터 환경의 보안 운영을 간소화합니다. S3 오브젝트용 FPolicy는 보안, 규정 준수 및 감사 요구사항을 위해 오브젝트 생성, 삭제 및 메타데이터 태그 변경을 모니터링하는 오브젝트 라이프사이클 가시성을 제공합니다. 이 기능은 성능에 영향을 주지 않고 무중단 모니터링을 제공합니다.

[[nas]]
== NAS

[cols="30%,70%"]
|===
| 업데이트 | 설명 


 a| 
xref:../smb-admin/supported-versions-functionality-concept.html[Windows 클라이언트를 위한 SMB 정규화 이름 쿼리 지원]
 a| 
Windows 클라이언트는 단일 요청으로 정규 파일 및 디렉터리 이름을 검색할 수 있으므로 파일 열기 지연 시간이 줄어들고 엔터프라이즈 데스크톱, 애플리케이션 및 파일 서버의 SMB 호환성이 향상됩니다. ONTAP은 열려 있는 파일 및 디렉터리에 대한 정규 경로를 자동으로 반환하여, 추가 구성 없이 Windows 11 24H2 이상 클라이언트에서 구성 요소별 조회를 방지합니다.



 a| 
xref:../nfs-admin/support-vmware-vstorage-over-nfs-concept.html[VMware NFS 데이터스토어를 위한 자동 공간 재확보]
 a| 
ONTAP은 VMware VAAI용 NetApp NFS 플러그인을 통해 NFS 데이터스토어에 대한 자동 공간 재확보를 지원합니다. 이는 VMware ESXi 9.0 이상 호스트에서 UNMAP 작업을 실행할 때 씬 프로비저닝된 VMDK 블록 범위에서 공간을 재확보하는 데 도움이 됩니다.



 a| 
xref:../volumes/cautions-increasing-maximum-directory-size-concept.html[ONTAP FlexVol 볼륨의 최대 디렉터리 크기]
 a| 
ONTAP은 최대 4GB의 디렉터리 크기를 지원하여 최대 약 2,500만 개의 파일을 포함하는 매우 큰 디렉터리의 성능을 향상시킵니다. AI 학습 등 단일 디렉터리에 매우 많은 파일을 생성하는 워크로드를 실행하는 고객은 기존에 대용량 디렉터리에서 발생했던 성능 저하를 방지하여 이점을 얻을 수 있습니다. 또한 데이터 보호 장애 조치 후에도 디렉터리가 완전히 인덱싱된 상태로 유지되도록 하여 복원력을 향상시키므로 SnapMirror 관계가 끊어지더라도 복제본이 우수한 성능을 발휘합니다. 이 기능은 MetroCluster 배포를 포함한 AFF 및 FAS 스토리지 시스템에서 사용할 수 있으며 필요에 따라 각 볼륨에서 활성화할 수 있습니다.



 a| 
xref:../task_nas_provide_client_access_with_name_services.html[SID를 UNIX ID로 자동 변환하는 기능 지원]
 a| 
ONTAP은 Windows SID에서 POSIX UID/GID를 생성하고 역변환하기 위해 LDAP에 연결된 SVM에 대한 자동 SID-UNIX ID 변환 지원을 도입했습니다. 이를 통해 Active Directory에서 uidNumber/gidNumber 속성을 수동으로 유지 관리할 필요가 없어지므로 관리 오버헤드가 줄어들고 NFS 및 SMB 전반에서 일관된 파일 액세스를 보장할 수 있습니다. 이 업계 표준 기능은 SSSD 기반 NAS 플랫폼에서 대규모 네트워크를 마이그레이션하고 ID 매핑 일관성을 유지하려는 고객에게 특히 유용합니다. 이 기능은 기본적으로 비활성화되어 있으며 SVM별로 구성됩니다.

 a|

[[s3-object-storage]]
== S3 오브젝트 스토리지

[cols="30%,70%"]
|===
| 업데이트 | 설명 


 a| 
xref:../s3-snapmirror/index.html#snapmirror-s3-requirements[MetroCluster의 SnapMirror S3 지원]
 a| 
SnapMirror S3 관계를 MetroCluster 구성에서 생성하여 스위치오버 및 스위치백 시에도 활성 사이트에서 계속 사용 가능하고 재개되도록 할 수 있습니다.



 a| 
xref:../s3-config/create-bucket-lifecycle-rule-task.html[ONTAP S3 버킷 수명 주기 관리에 대한 MetroCluster 지원]
 a| 
MetroCluster 구성에서 기본 S3 버킷에 대한 ONTAP S3 버킷 수명 주기 관리 규칙을 생성할 수 있습니다.



 a| 
xref:../s3-config/create-s3-object-store-server-task.html[유연한 S3 버킷 크기 조정]
 a| 
ONTAP은 새 S3 버킷에 대한 구성 가능한 기본 크기를 지원합니다. 이를 통해 애플리케이션이 용량을 지정하지 않고 S3 API를 통해 버킷을 생성할 때 수동 크기 조정을 줄일 수 있습니다. 기본 크기가 구성되지 않은 경우 버킷 생성 동작은 변경되지 않습니다.



 a| 
xref:../s3-multiprotocol/create-nas-bucket-task.html[FlexVol 오리진이 있는 FlexCache 볼륨의 S3 NAS 버킷]
 a| 
S3 NAS 버킷은 FlexVol 오리진이 있는 FlexCache 볼륨에서 지원됩니다. 단일 오브젝트 S3 작업(PUT, GET, DELETE, HEAD, LIST)이 지원됩니다. 기본 FlexVol 볼륨이 Granular Data Distribution을 지원하지 않으므로 멀티파트 업로드는 지원되지 않습니다.



 a| 
xref:../s3-multiprotocol/create-nas-bucket-task.html[FlexCache 볼륨의 NAS 버킷에 대한 S3 서버 측 복사 지원]
 a| 
FlexCache 볼륨의 S3 NAS 버킷은 S3 CopyObject 및 UploadPartCopy API를 사용하여 서버 측 오브젝트 복사 작업을 지원합니다. 동일한 FlexCache NAS 버킷 내에서 오브젝트를 복사하거나 FlexGroup 볼륨으로 지원되는 S3 NAS 버킷에서 FlexCache NAS 버킷으로 오브젝트를 복사할 수 있습니다.



 a| 
xref:../s3-config/ontap-s3-supported-actions-reference.html[ONTAP S3 유연한 체크섬 지원]
 a| 
ONTAP S3는 S3 NAS 버킷에 대해 AWS 호환 CRC-64NVME 체크섬을 지원합니다. S3 클라이언트가 지원되는 업로드 및 멀티파트 작업에 대한 체크섬 정보를 제공하면 ONTAP은 체크섬을 검증 및 저장하고 지원되는 GET 및 HEAD 요청에 대한 체크섬 정보를 반환합니다.

관리 연결 폭주 및 사전 클러스터링 개선을 위한 Apache 공정 대기열

ONTAP은 관리 연결 폭주 시 REST, System Manager 및 ONTAPI에 대한 액세스를 유지할 수 있도록 관리 웹 서버에 선택적(기본값 비활성화) 소스 IP 공정 큐잉을 도입합니다. 또한 ONTAP은 사전 클러스터 전용 REST API를 통한 이미지 설치를 지원하고 동적 호스트 구성 프로토콜(DHCP) 처리를 개선하여, 노드가 클러스터 설정을 기다리는 동안 임대 갱신 및 IP 주소 변경 시에도 사전 클러스터 노드 관리 LIF를 계속 사용할 수 있도록 합니다.



 a| 
xref:../anti-ransomware/modify-snapshot-options-arpai.html[ARP/AI 스냅샷 응답 정책에 대한 향상된 제어 기능]
 a| 
ARP/AI 스냅샷 응답 정책은 SVM 또는 볼륨 수준에서 구성하여 ARP/AI가 비정상적인 활동을 감지했을 때 스냅샷을 생성할지 여부를 제어할 수 있습니다. 세 가지 정책을 사용할 수 있습니다.  `alert-with-proactive-and-periodic-snapshot`(기본값, 기존 동작 유지),  `alert-with-proactive-snapshot`(공격 스냅샷만 생성, 주기적 스냅샷 없음) 및  `alert-only`(경고 및 이벤트 로그만 생성, 스냅샷 생성 안 됨). 9.20.1로 업그레이드한 후에는 해당 노드 수준 옵션이 이전에 수정되지 않은 경우 기본 주기적 스냅샷 최대 개수가 6에서 2로, 기본 보존 기간이 12시간에서 7시간으로 변경됩니다.



 a| 
xref:../encryption-at-rest/enable-external-key-management-96-later-nve-task.html[데이터 SVM을 위한 키 관리 워크플로 개선 사항]
 a| 
데이터 SVM에서 외부 키 관리자를 활성화하면 ONTAP은 해당 SVM의 볼륨 암호화 키를 관리자 범위 키 관리자에서 새 데이터 SVM 키 관리자로 자동으로 마이그레이션할 수 있습니다. 이를 통해 외부 키 관리로의 전환이 간소화되고 표준 워크플로에서 별도의 수동 마이그레이션 단계를 제거할 수 있습니다.



 a| 
xref:../multi-admin-verify/index.html[MAV 승인자로서 IdP, AD 및 LDAP 그룹 지원]
 a| 
MAV 승인 그룹에는 개별 관리자 외에도 ID 공급자(IdP), Active Directory(AD) 및 LDAP(nsswitch) 그룹을 승인자로 포함할 수 있습니다. 지원되는 그룹 유형에는 Entra ID, ADFS, AD 도메인 그룹 및 LDAP 그룹이 있습니다. IdP, AD 또는 LDAP 디렉터리에서 사용자를 추가하거나 제거해도 MAV 구성을 변경할 필요가 없습니다. 사용자의 그룹 멤버십 변경 사항은 사용자가 다음에 로그인할 때 재인증 후 적용됩니다. security multi-admin-verify registered-operations show 명령을 사용하여 현재 클러스터에서 사용 가능한 모든 MAV 보호 가능 작업을 표시할 수 있습니다.



 a| 
xref:../networking/configure_snmpv3_users_in_a_cluster.html[SNMPv3 SHA-512 인증 지원]
 a| 
ONTAP은 SNMPv3 사용자에 대해 SHA-512 인증을 지원합니다. 이 개선 사항을 통해 SHA-512 인증이 필요한 스위치 등 외부 SNMP 클라이언트 및 스위치 모니터링에 더욱 강력한 SNMPv3 인증을 사용할 수 있습니다. 자세한 내용은 ONTAP 클러스터에서 SNMPv3 사용자 구성 및 이더넷 스위치 상태 모니터링을 위한 SNMPv3 구성을 참조하십시오.

자세한 내용은 https://docs.netapp.com/us-en/ontap-systems-switches/switch-cshm/config-snmpv3.html["이더넷 스위치 상태 모니터링을 위한 SNMPv3 구성"]을 참조하십시오.

스토리지 효율성 데이터 감소율(DRR)은 감소 가능한 데이터만 포함하여 ONTAP 스토리지 효율성 공간 절약에 대한 보다 정확한 평가를 제공합니다. ONTAP 9.19.1 및 이전 버전에서는 DRR에 감소 가능한 데이터와 감소 불가능한 데이터가 모두 포함됩니다.

DP 볼륨(SnapMirror 전송) 및 글로벌 중복 제거 세션의 중복 제거 작업은 일반 볼륨 중복 제거와 함께 관리되므로 경합 및 메타데이터 증가를 줄입니다. 특히 혼합 워크로드 환경에서 구성 변경 없이 스토리지 효율성을 향상시킬 수 있습니다. 이 기능은 기본적으로 활성화되어 있으며 AFF 스토리지 시스템에서 사용할 수 있습니다.

MetroCluster IP 구성의 일부인 SVM에 대해 스토리지 제한을 구성할 수 있습니다.

FlexCache 볼륨 메트릭
 a| 
FlexCache 볼륨 메트릭은 FlexCache 볼륨과 원본 볼륨 간에 교환되는 데이터 및 메타데이터의 양을 보고합니다. 기존 ONTAP REST 볼륨 통계 및 메트릭 엔드포인트에 FlexCache에서 원본으로, 원본에서 FlexCache로의 데이터 전송에 대한 가시성을 제공하는 두 가지 새로운 속성이 추가되었습니다. 카운터는 구성이 필요 없이 자동으로 수집되며, 용량 계획, 성능 분석, 네트워크 문제 해결 및 비용 분석에 유용합니다. 이 기능을 사용하려면 FlexCache 및 원본 노드 모두에 ONTAP 9.20 이상이 필요합니다. 자세한 내용은 link:https://docs.netapp.com/us-en/ontap-automation["ONTAP 자동화"^] 설명서를 참조하십시오.



 a| 
클러스터 내 재균형 조정
 a| 
ONTAP은 워크로드 및 클러스터 용량이 변화함에 따라 관리 노력을 최소화하면서 클러스터 성능을 최적으로 유지할 수 있도록 두 가지 새로운 균형 배치 기능을 도입했습니다. 프로비저닝 시 배치 제어를 통해 고객은 REST API를 통해 새 볼륨을 배치할 때 성능 또는 공간 요구사항 중 어떤 것을 우선시할지 지정할 수 있습니다. 공간 성능 재조정(SPR)은 클러스터 전체에서 발생하는 성능 핫스팟이나 애그리게이트 공간 압박을 지속적으로 찾는 백그라운드 프로세스입니다. 구성된 모드에 따라 SPR은 EMS 알림을 통해 교정 볼륨 이동을 권장하거나 표준 및 무중단 ONTAP 볼륨 이동 작업을 사용하여 자동으로 이동을 수행합니다. 자세한 내용은 link:https://docs.netapp.com/us-en/ontap-automation["ONTAP 자동화"^] 설명서를 참조하십시오.

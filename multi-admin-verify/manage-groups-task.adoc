= MAV에 대한 ONTAP 관리자 승인 그룹을 관리합니다
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
MAV(Multi-admin verification)를 활성화하기 전에 승인 또는 거부권을 부여할 관리자가 하나 이상 포함된 관리자 승인 그룹을 만들어야 합니다. 다중 관리자 확인을 활성화한 경우 승인 그룹 구성원을 수정하려면 기존의 검증된 관리자 중 한 명의 승인이 필요합니다.

.이 작업에 대해
기존 관리자를 MAV 그룹에 추가하거나 새 관리자를 만들 수 있습니다.

MAV 기능은 기존의 역할 기반 액세스 제어(RBAC) 설정을 그대로 사용합니다. 잠재적인 MAV 관리자는 MAV 관리자 그룹에 추가하기 전에 보호 작업을 실행할 수 있는 충분한 권한이 있어야 합니다. link:../authentication/create-svm-user-accounts-task.html["RBAC에 대해 자세히 알아보십시오."]

승인 요청이 보류 중이라는 것을 MAV 관리자에게 알리도록 MAV를 구성할 수 있습니다. 이렇게 하려면 이메일 알림(특히, 'Mail From' 및 'Mail Server' 매개 변수)을 구성하거나 이러한 매개 변수를 지워 알림을 비활성화해야 합니다. 이메일 알림이 없으면 MAV 관리자는 승인 대기열을 수동으로 확인해야 합니다.

ONTAP 9.15.1부터 Active Directory(AD) 사용자를 MAV 관리자로 구성할 수 있습니다.  AD 사용자는 다음과 같아야 합니다.link:../authentication/grant-access-active-directory-users-groups-task.html["ONTAP 관리자로 구성됨"] .

ONTAP 9.20.1부터 승인 그룹에는 ID 공급자(IdP), Active Directory(AD) 또는 LDAP(nsswitch) 그룹도 포함될 수 있습니다. 지원되는 그룹 유형에는 Entra ID(이전 Azure AD), ADFS, AD 도메인 그룹 및 LDAP 그룹이 포함됩니다.

ID 공급자에서 사용자의 그룹 멤버십을 변경하면 사용자가 다음에 성공적으로 로그인할 때 적용됩니다. MAV를 다시 구성할 필요는 없습니다.


NOTE: MAV 승인 그룹에 IdP, AD 또는 LDAP 그룹을 추가하기 전에 해당 그룹에 로그인 액세스가 이미 구성되어 있고 역할 매핑과 함께  `security login group` 테이블에 등록되어 있어야 합니다. 다음 절차를 참조하십시오.



[[system-manager-procedure]]
== System Manager 절차

처음으로 MAV 승인 그룹을 만들려면 System Manager 절차 - 를 참조하십시오 link:enable-disable-task.html#system-manager-procedure["다중 관리 검증을 활성화합니다."]

기존 승인 그룹을 수정하거나 추가 승인 그룹을 만들려면:

. 여러 관리자 검증을 받을 관리자 식별
+
.. *클러스터 > 설정*을 선택합니다.
.. *사용자, 그룹 및 역할* 옆의 image:icon_arrow.gif["화살표 아이콘"]를 선택합니다.
.. *사용자* 아래에서 image:icon_add.gif["추가 아이콘"]을(를) 선택합니다.
.. 필요에 따라 명단을 수정합니다.
+
자세한 내용은 을 참조하십시오 link:../task_security_administrator_access.html["관리자 액세스 제어."]



. ONTAP 9.20.1부터 IdP, AD 또는 LDAP 그룹을 MAV 승인자로 추가하려면, MAV 구성에서 참조할 수 있도록 먼저 해당 그룹을 등록하십시오.
+
.. *그룹*에서 image:icon_add.gif["추가 아이콘"]을(를) 선택하여 그룹을 추가합니다.
+
그룹 이름을 입력하십시오. UUID 필드는 Microsoft Entra 그룹의 경우에만 필수이며, 다른 ID 공급자는 그룹 이름을 사용합니다.

.. *그룹-역할 매핑*에서 image:icon_add.gif["추가 아이콘"]을 선택하고 그룹을 선택한 다음 MAV 요청을 승인할 수 있는 충분한 권한이 있는 역할을 할당합니다.


. MAV 승인 그룹 생성 또는 수정:
+
.. *클러스터 > 설정*을 선택합니다.
.. *Security* 섹션에서 *Multi-Admin Approval* 옆의 image:icon_arrow.gif["화살표 아이콘"]을(를) 선택합니다. (MAV가 아직 구성되지 않은 경우 image:icon_gear.gif["작업 아이콘"] 아이콘이 표시됩니다.)
+
*** 이름: 그룹 이름을 입력합니다.
*** 승인자(사용자): 사용자 목록에서 개별 승인자를 선택합니다.
*** 승인자(그룹): ONTAP 9.20.1 버전부터는 등록된 IdP, AD 또는 LDAP 그룹을 하나 이상 선택적으로 지정할 수 있습니다.
*** 이메일 주소: 이메일 주소를 입력합니다.
*** Default group(기본 그룹): 그룹을 선택합니다.






MAV가 활성화되면 기존 구성을 편집하려면 MAV 승인이 필요합니다.



[[cli-procedure]]
== CLI 절차

. 'Mail From' 및 'Mail Server' 매개 변수에 값이 설정되어 있는지 확인합니다. 입력:
+
이벤트 구성 쇼

+
디스플레이는 다음과 비슷해야 합니다.

+
[listing]
----
cluster01::> event config show
                           Mail From:  admin@localhost
                         Mail Server:  localhost
                           Proxy URL:  -
                          Proxy User:  -
 Publish/Subscribe Messaging Enabled:  true
----
+
이러한 매개 변수를 구성하려면 다음을 입력합니다.

+
''이벤트 구성 수정-메일-보낸 사람_이메일_주소_-메일-서버_서버_이름_'

+
및 `event config modify` 에 대한 자세한 `event config show` 내용은 을 link:https://docs.netapp.com/us-en/ontap-cli/search.html?q=event+config["ONTAP 명령 참조입니다"^]참조하십시오.

. 다중 관리자 인증에 참여할 관리자를 지정합니다.
+
[cols="50,50"]
|===
| 원하는 사항 | 이 명령을 입력합니다 


| 현재 관리자를 표시합니다  a| 
'보안 로그인 쇼'



| 현재 관리자의 자격 증명을 수정합니다  a| 
'Security login modify_<parameters>_'



| 새 관리자 계정을 만듭니다  a| 
'Security login create-user-or-group-name_admin_name_-application ssh-authentication-method password

|===
+
에 대한 자세한 `security login show` `security login modify` 내용은, 및 `security login create`link:https://docs.netapp.com/us-en/ontap-cli/search.html?q=security+login["ONTAP 명령 참조입니다"^] 을 참조하십시오.

. ONTAP 9.20.1부터 IdP, AD 또는 LDAP 그룹을 MAV 승인자로 추가하려면 해당 그룹에 로그인 액세스가 구성되어 있는지 확인한 다음 MAV에 등록해야 합니다.
+
해당 그룹에 로그인 액세스 권한이 구성되어 있지 않은 경우 다음을 입력하십시오:

+
`security login create -user-or-group-name _group_name_ -application http|ssh -authentication-method domain|nsswitch|saml|oauth2 -role _role_`

+
다음으로 MAV 구성에서 참조할 수 있도록 그룹을 등록하고 역할에 매핑합니다:

+
`security login group create -vserver _svm_name_ -name _group_name_ [-uuid _uuid_]`

+
`security login group role-mapping create -group-id _group_id_ -role _role_`

+
해당  `-uuid` 매개변수는 Microsoft Entra ID 그룹에만 필요합니다. AD 도메인, ADFS/SAML 및 LDAP(nsswitch) 그룹은 이름으로만 식별됩니다.

+
*예시:* 다음 명령은 MAV용 AD 그룹 `mydomain\mav_approvers`을 등록하고 해당 그룹을  `admin` 역할에 매핑합니다.

+
[listing]
----
cluster-1::> security login group create -vserver cluster-1 -name mydomain\mav_approvers
cluster-1::> security login group show -vserver cluster-1

     Vserver: cluster-1
  Group Name: mydomain\mav_approvers
    Group ID: 1
  Group UUID: -
     Comment: -

cluster-1::> security login group role-mapping create -group-id 1 -role admin
----
+
 `security login group create` 및 `security login group role-mapping create`에 대한 자세한 내용은 link:https://docs.netapp.com/us-en/ontap-cli/search.html?q=security+login+group["ONTAP 명령 참조입니다"^]을 참조하십시오.

. MAV 승인 그룹 생성:
+
`security multi-admin-verify approval-group create [ -vserver _svm_name_] -name _group_name_ [-approvers _approver1_[,_approver2_…]] [-groups _group1_[,_group2_…]] [[-email _address1_], _address1_...]`

+
** '-vserver' - 이번 릴리즈에서는 관리 SVM만 지원됩니다.
** '-name' - 최대 64자의 MAV 그룹 이름입니다.
** `-approvers` - 한 명 이상의 개별 승인자 목록입니다. AD 사용자의 경우  `domain\user` 형식을 사용하십시오. 예:  `mydomain\pavan`.
** `-groups` - 승인 그룹에 포함할 하나 이상의 IdP, AD 또는 LDAP 그룹 목록입니다. 각 그룹은 역할 매핑과 함께  `security login group` 테이블에 이미 등록되어 있어야 합니다.
** '-email' - 요청을 작성, 승인, 거부하거나 실행할 때 통지되는 하나 이상의 이메일 주소입니다.
+
*예시:* 다음 명령은 두 명의 개별 승인자와 하나의 Entra ID 그룹으로 구성된 MAV 그룹을 생성합니다.

+
[listing]
----
cluster-1::> security multi-admin-verify approval-group create -name mav-grp1 -approvers pavan,julia -groups entra-group-mav-approvers -email pavan@myfirm.com,julia@myfirm.com
----


. 그룹 생성 및 구성원 자격 확인:
+
`security multi-admin-verify approval-group show`

+
* 예: *

+
[listing]
----
cluster-1::> security multi-admin-verify approval-group show
Vserver  Name        Approvers        Approver Groups                  Email
-------  ---------------- ------------------  ------------------------------- ------------------------------------------------------------
svm-1    mav-grp1   pavan,julia      entra-group-mav-approvers        pavan@myfirm.com,julia@myfirm.com
----


이 명령을 사용하여 초기 MAV 그룹 구성을 수정합니다.

* 참고: * 모두 실행 전에 MAV 관리자의 승인이 필요합니다.

[cols="50,50"]
|===
| 원하는 사항 | 이 명령을 입력합니다 


| 그룹 특성을 수정하거나 기존 구성원 정보를 수정합니다  a| 
`security multi-admin-verify approval-group modify [-vserver _svm_name_] -name _group_name_ [-approvers _approver1_[,_approver2_…]] [-groups _group1_[,_group2_…]] [[-email _address1_], _address1_...]`



| 구성원을 추가 또는 제거합니다  a| 
`security multi-admin-verify approval-group replace [-vserver _svm_name_] -name _group_name_ [-approvers-to-add _approver1_[,_approver2_…]][-approvers-to-remove _approver1_[,_approver2_…]] [-groups-to-add _group1_[,_group2_…]][-groups-to-remove _group1_[,_group2_…]]`



| 그룹을 삭제합니다  a| 
'보안 multi-admin-verify approval-group delete[-vserver_svm_name_]-name_group_name_'

|===

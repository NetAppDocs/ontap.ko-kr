= ONTAP 관리자 암호를 변경합니다
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
클러스터의 보안을 유지하려면 처음 로그인한 직후와 그 이후에도 정기적으로 초기 ONTAP 관리자 암호를 변경해야 합니다.

ONTAP 9.20.1부터 사용자 계정에 암호 만료 알림이 구성되어 있으면 System Manager에서 암호 만료 14일 전부터 배너 알림을 표시합니다. 이 알림은 로그인할 때마다 업데이트되어 남은 일수를 보여줍니다.

.이 작업에 대해
새 암호는 다음 규칙을 준수해야 합니다.

* 사용자 이름은 포함할 수 없습니다
* 8자 이상이어야 합니다
* 하나 이상의 문자와 숫자를 포함해야 합니다
* 마지막 여섯 개의 암호와 같을 수 없습니다



NOTE: 명령을 사용하여 지정된 역할과 연결된 계정의 암호 규칙을 수정할 수 `security login role config modify` 있습니다.

.시작하기 전에
* 암호를 변경하려면 클러스터 또는 SVM 관리자여야 합니다.
* 다른 관리자의 암호를 변경하려면 클러스터 관리자여야 합니다.


.단계
System Manager 또는 ONTAP 명령줄 인터페이스(CLI)를 사용하여 암호를 변경하십시오.

[role="tabbed-block"]
====
.시스템 관리자
--
. System Manager에서 * 클러스터 > 설정 * 을 선택합니다.
. *사용자 및 역할*에서 *사용자*를 선택합니다.
. 비밀번호를 변경해야 하는 사용자 계정 옆의 image:icon_kabob.gif["메뉴"]을(를) 선택한 다음 *비밀번호 변경*을 선택합니다.
. 새 비밀번호를 입력하세요.
. 새 비밀번호를 다시 입력하여 확인한 다음 *저장*을 선택하십시오.


--
.CLI를 참조하십시오
--
SVM 관리자인 경우  `security login password` 명령어를 사용하여 본인의 비밀번호를 변경할 수 있습니다. 클러스터 관리자인 경우  `security login password` 명령어를 사용하여 모든 관리자의 비밀번호를 변경할 수 있습니다.

. 관리자 암호 변경: `security login password -vserver _svm_name_ -username _user_name_`
+
다음 명령은 SVM `vs1.example.com`의 관리자 `admin1` 암호를 변경합니다. 현재 암호를 입력하라는 메시지가 표시되면 새 암호를 입력하고 다시 입력합니다.

+
[listing]
----
vs1.example.com::>security login password -vserver engData -username admin1
Please enter your current password:
Please enter a new password:
Please enter it again:
----

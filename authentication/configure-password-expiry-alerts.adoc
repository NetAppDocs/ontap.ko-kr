= System Manager에서 ONTAP 사용자 암호 만료 알림 구성
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ONTAP 9.20.1부터 사용자 계정과 연결된 역할에 암호 만료 알림이 구성되어 있으면, 암호 만료 14일 전부터 System Manager에 로그인한 직후 페이지 상단에 배너 알림이 표시됩니다. 이 알림은 사용자가 로그인할 때마다 업데이트되어 암호 만료까지 남은 일수를 보여줍니다. 관리자 역할을 추가하거나 편집할 때 만료 알림을 구성할 수 있습니다.

.단계
. 클러스터 > 설정 * 을 선택합니다.
. *사용자 및 역할* 옆의 image:icon_arrow.gif["화살표 아이콘"]을(를) 선택합니다.
. 사용자 역할을 추가하거나 편집할 때 암호 만료 알림을 구성합니다.
+
** 사용자 역할을 추가할 때 구성하려면 *역할* 아래에서 image:icon_add.gif["아이콘 추가"]을(를) 선택합니다. 역할 이름을 입력한 다음 암호 만료 기간과 암호 만료 알림을 선택합니다.
** 사용자 역할을 편집할 때 구성하려면 *역할*에서 해당 사용자 역할을 선택합니다. *편집*을 선택한 다음 암호 만료 기간을 선택합니다.
** 추가 * 를 선택합니다.




.결과
사용자는 비밀번호가 만료되기 전 선택한 일수부터 System Manager에 로그인한 직후 페이지 상단 배너 알림을 받습니다. 이 알림은 사용자가 로그인할 때마다 업데이트되어 비밀번호 만료일까지 남은 일수를 표시합니다.

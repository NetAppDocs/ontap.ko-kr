= ONTAP Vscan 서버 설치 및 구성
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
하나 이상의 Vscan 서버를 설정하여 시스템의 파일에 바이러스가 있는지 검사합니다. 공급업체에서 제공한 지침에 따라 서버에 바이러스 백신 소프트웨어를 설치하고 구성합니다.

NetApp에서 제공하는 README 파일의 지침에 따라 ONTAP Antivirus Connector를 설치하고 구성하십시오. 또는 link:install-ontap-antivirus-connector-task.html["ONTAP 안티바이러스 커넥터 설치 페이지를 참조하십시오"] 지침을 따르십시오.

[NOTE]
====
재해 복구 및 MetroCluster 구성의 경우 기본/로컬 및 보조/파트너 ONTAP 클러스터에 대해 별도의 Vscan 서버를 설정 및 구성해야 합니다.

====


[[antivirus-software-requirements]]
== 안티바이러스 소프트웨어 요구 사항

* 안티바이러스 소프트웨어 요구 사항에 대한 자세한 내용은 공급업체 설명서를 참조하십시오.
* Vscan에서 지원하는 공급업체, 소프트웨어 및 버전에 대한 자세한 내용은 link:../antivirus/vscan-partner-solutions.html["Vscan 파트너 솔루션"]을(를) 참조하십시오.




[[ontap-antivirus-connector-requirements]]
== ONTAP 안티바이러스 커넥터 요구 사항

각 SVM은 ICAP 또는 Antivirus Connector 중 하나만 사용하며, 둘 다 사용하지는 않습니다.

* NetApp 지원 사이트의 link:http://mysupport.netapp.com/NOW/cgi-bin/software["소프트웨어 다운로드"^] 페이지에서 ONTAP Antivirus Connector를 다운로드할 수 있습니다.
* ONTAP 안티바이러스 커넥터에서 지원되는 Windows 버전 및 상호 운용성 요구 사항에 대한 자세한 내용은 을 참조하십시오link:../antivirus/vscan-partner-solutions.html["Vscan 파트너 솔루션"].
+
[NOTE]
====
하나의 클러스터에 다른 Vscan 서버용으로 다양한 버전의 Windows 서버를 설치할 수 있습니다.

====
* Windows 서버에 .NET 3.0 이상이 설치되어 있어야 합니다.
* Windows 서버에서 SMB 2.0을 활성화해야 합니다.




[[icap-capable-scan-engine-requirements]]
== ICAP 지원 스캔 엔진 요구 사항

각 SVM은 ICAP 또는 Antivirus Connector 중 하나만 사용하며, 둘 다 사용하지는 않습니다.

* ONTAP 9.20.1부터 ONTAP은 안티바이러스 커넥터가 필요 없는 ICAP 기반 스캔 경로를 지원합니다.
* ICAP는 Linux 기반 스캔 엔진을 지원하며 Windows, .NET 또는 SMB 2.0을 필요로 하지 않습니다.



NOTE: ONTAP 9.20.1에서 이전 버전으로 되돌리려면 먼저 모든 ICAP 구성을 제거해야 합니다.

link:icap-vscan.html["ICAP 기반 Vscan 구성"]에 대해 자세히 알아보십시오.

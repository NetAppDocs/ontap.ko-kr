= ONTAP System Manager를 사용하여 VMware 데이터 저장소에 NFS 스토리지 프로비저닝
:hardbreaks:
:toclevels: 1
:allow-uri-read: 
:toclevels: 1
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
ONTAP tools for VMware vSphere를 사용하여 ESXi 호스트용 ONTAP 기반 스토리지 시스템에 NFS 볼륨을 프로비저닝하기 전에 ONTAP 9.7 이상의 System Manager를 사용하여 NFS를 활성화하십시오.

시스템 관리자에서 link:task_nas_enable_linux_nfs.html["NFS 지원 스토리지 VM"]을 생성한 후 ONTAP tools for VMware vSphere를 사용하여 NFS 볼륨을 프로비저닝하고 데이터 저장소를 관리합니다.

현재 사용 중인 ONTAP과 ONTAP tools for VMware vSphere 릴리스 간의 호환성을 확인하려면 반드시  https://imt.netapp.com/matrix/["NetApp 상호 운용성 매트릭스"^]을 확인하십시오.

System Manager Classic(ONTAP 9.7 이하 버전용)을 사용하여 ESXi 호스트의 데이터스토어에 대한 NFS 액세스를 설정하려면 다음을 참조하십시오. https://docs.netapp.com/us-en/ontap-system-manager-classic/nfs-config-esxi/index.html["ESXi용 NFS 구성 개요"^]

자세한 내용은  https://docs.netapp.com/us-en/netapp-solutions/virtualization/vsphere_ontap_ontap_for_vsphere.html["TR-4597: ONTAP용 VMware vSphere"^] 및  https://docs.netapp.com/us-en/ontap-tools-vmware-vsphere-10/["VMware vSphere용 ONTAP 툴 설명서"^]을 참조하십시오.

= MetroCluster IP 및 SnapMirror 활성 동기화를 위한 ONTAP Mediator에 대해 알아보십시오.
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ONTAP Mediator는 고가용성(HA) 메타데이터를 위한 영구적이고 격리된 저장소와 쿼럼 결정을 돕는 동기식 노드 상태 쿼리 기능을 제공하고 컨트롤러 활성 상태를 위한 핑 프록시 역할을 수행하여 SnapMirror 활성 동기화 및 MetroCluster IP를 지원합니다.

ONTAP Mediator는 ONTAP 클러스터와는 별도의 제3 장애 도메인에 있는 Linux 호스트에서 실행되며, HA 메타데이터를 위한 영구적이고 펜싱된 저장소를 제공합니다. ONTAP은 이 저장소와 Mediator의 노드 상태 조회 및 핑 프록시 기능을 사용하여 SnapMirror 활성 동기화 관계 및 MetroCluster IP 구성을 모니터링합니다.

* ONTAP Mediator는 노드 관리 LIF와 클러스터 관리 LIF를 사용하여 여러 개의 이중화된 경로를 통해 각 클러스터와 통신합니다. 이를 통해 ONTAP은 전체 사이트 장애와 단일 InterSwitch 링크(ISL) 장애를 구분할 수 있습니다.
* SnapMirror 활성 동기화에서 클러스터가 피어 및 ONTAP Mediator와의 연결을 모두 잃으면 ONTAP은 피어에 연결할 수 없는 것으로 간주하고 자동으로 남아 있는 복사본으로 페일오버할 수 있습니다.
* MetroCluster IP 구성에서 ONTAP Mediator는 MetroCluster 노드에 대한 상태 정보를 저장하고 장애 발생 시 적절한 조치를 결정하는 데 도움을 줌으로써 MAUSO(Mediator 지원 자동 계획되지 않은 스위치오버)를 지원합니다.


ONTAP Mediator의 온프레미스 버전을 설치하거나 업그레이드하려면 link:https://docs.netapp.com/us-en/ontap-mediator/index.html["ONTAP Mediator 문서"^]을(를) 참조하십시오.

ONTAP 9.17.1부터 사용 가능한 ONTAP Cloud Mediator에 대한 자세한 내용은 link:../snapmirror-active-sync/index.html["SnapMirror Active Sync 설명서"]을(를) 참조하십시오.

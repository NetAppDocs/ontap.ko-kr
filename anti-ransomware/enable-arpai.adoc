= 볼륨에서 ONTAP ARP/AI 활성화
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ONTAP 9.16.1부터 기존 볼륨에서 AI를 사용한 자율 랜섬웨어 방어(ARP/AI)를 활성화하거나 ARP/AI가 활성화된 새 볼륨을 생성할 수 있습니다. ARP/AI는 학습 기간 없이 즉시 활성화됩니다.


NOTE: ONTAP 9.15.1 이하 버전을 사용 중인 경우 link:enable-arp.html["볼륨에서 ARP 활성화"]을 참조하십시오.

.이 작업에 대해
ARP/AI는 ONTAP 9.16.1 이상 버전에서 사용되는 최신 랜섬웨어 보호 모델입니다. ARP/AI를 활성화하려면 환경이 요구 사항을 충족하는지 확인한 후 환경에 맞는 절차를 따르십시오.

* <<enable-nas-flexvol,FlexVol 볼륨이 있는 NAS>> (ONTAP 9.16.1 이상)
* <<enable-nas-flexgroup,FlexGroup 볼륨이 있는 NAS>> (ONTAP 9.18.1 이상)
* <<enable-san,SAN 볼륨>> (ONTAP 9.17.1 이상)


자율형 랜섬웨어 보호 기능을 활성화한 후에는 환경 및 ONTAP 버전에 따라 전환 기간이 시작될 수 있습니다.

[cols="25,25,50"]
|===
| 볼륨 유형입니다 | ONTAP 버전입니다 | 활성화 후의 동작 


.2+| NAS FlexGroup | ONTAP 9.18.1 이상 | ARP/AI는 학습 기간 없이 즉시 활성화됩니다. 


| ONTAP 9.13.1부터 9.17.1까지 | ARP는 30일 동안 학습 모드로 시작됩니다. 


.2+| NAS FlexVol | ONTAP 9.16.1 이상 | ARP/AI는 학습 기간 없이 즉시 활성화됩니다. 


| ONTAP 9.10.1부터 9.15.1까지 | ARP는 30일 동안 학습 모드로 시작됩니다. 


| SAN 볼륨 | ONTAP 9.17.1 이상 | ARP/AI는 즉시 활성화되어 초기 보수적 임계값에서 전환하기 전에 적절한 경고 임계값을 설정하기 위한 평가 기간을 시작합니다. 
|===
.시작하기 전에
ARP/AI를 활성화하기 전에 환경에 다음 사항이 있는지 확인하십시오.

.NAS 특정 요구 사항
* NFS 또는 SMB(또는 둘 다) 프로토콜이 활성화된 스토리지 VM(SVM)입니다.
* 클라이언트가 구성된 NAS 작업 부하.
* 활동적인link:../concepts/namespaces-junction-points-concept.html["접합 경로"] 볼륨을 위해서.


.SAN 특정 요구 사항
* iSCSI, FC 또는 NVMe 프로토콜이 활성화된 스토리지 VM(SVM).
* 클라이언트가 구성된 SAN 워크로드.


.일반 요구 사항
* 사용하시는 ONTAP 버전에 대한 link:index.html#licenses-for-autonomous-ransomware-protection["올바른 라이센스입니다"].
* (권장) 다중 관리자 검증(MAV)이 활성화되어 있습니다(ONTAP 9.13.1 이상). 보다link:../multi-admin-verify/enable-disable-task.html["다중 관리 검증을 활성화합니다"] .

== NAS FlexVol 볼륨에서 ARP/AI 활성화

ONTAP 9.16.1부터 NAS FlexVol 볼륨의 경우 ARP/AI가 활성화 직후 바로 작동합니다.

[role="tabbed-block"]
====
.시스템 관리자
--
. 스토리지 > 볼륨 * 을 선택한 다음 보호할 볼륨을 선택합니다.
. 볼륨 * 개요의 * 보안 * 탭에서 * 상태 * 를 선택하여 비활성화에서 활성화로 전환합니다.
. *랜섬웨어 방지* 상자에서 볼륨의 ARP/AI 상태를 확인하십시오.
+
모든 볼륨의 ARP/AI 상태를 표시하려면 *볼륨* 창에서 *표시/숨기기*를 선택한 다음 *랜섬웨어 방지* 상태가 선택되어 있는지 확인하십시오.



--
.CLI를 참조하십시오
--
*기존 볼륨에서 ARP/AI 활성화:*

[source, cli]
----
security anti-ransomware volume enable -volume <vol_name> -vserver <svm_name>
----
*ARP/AI가 활성화된 새 볼륨 생성:*

[source, cli]
----
volume create -volume <vol_name> -vserver <svm_name> -aggregate <aggr_name> -size <nn> -anti-ransomware-state enabled -junction-path </path_name>
----
*ARP/AI 상태를 확인하십시오:*

[source, cli]
----
security anti-ransomware volume show
----
에 대한 자세한 내용은 `security anti-ransomware volume show` link:https://docs.netapp.com/us-en/ontap-cli/security-anti-ransomware-volume-show.html["ONTAP 명령 참조입니다"^]을 참조하십시오.

--
====

== NAS FlexGroup 볼륨에서 ARP/AI 활성화

ONTAP 9.18.1부터 FlexGroup 볼륨에 대해 ARP/AI가 활성화 직후 바로 작동합니다.


NOTE: ONTAP 9.13.1부터 9.17.1까지의 FlexGroup 볼륨은 이전 ARP 모델을 사용하므로 학습 기간이 필요합니다. link:enable-arp.html#enable-arp-on-nas-flexgroup-volumes["NAS FlexGroup 볼륨에서 ARP 활성화"]을 참조하십시오.

[role="tabbed-block"]
====
.시스템 관리자
--
. *저장소 > 볼륨*을 선택한 다음 보호하려는 FlexGroup 볼륨을 선택합니다.
. 볼륨 * 개요의 * 보안 * 탭에서 * 상태 * 를 선택하여 비활성화에서 활성화로 전환합니다.
. *랜섬웨어 방지* 상자에서 볼륨의 ARP/AI 상태를 확인하십시오.
+
모든 볼륨의 ARP/AI 상태를 표시하려면 *볼륨* 창에서 *표시/숨기기*를 선택한 다음 *랜섬웨어 방지* 상태가 선택되어 있는지 확인하십시오.



--
.CLI를 참조하십시오
--
*기존 FlexGroup 볼륨에서 ARP/AI 활성화:*

[source, cli]
----
security anti-ransomware volume enable -volume <vol_name> -vserver <svm_name>
----
*ARP/AI가 활성화된 새 FlexGroup 볼륨을 생성합니다:*

[source, cli]
----
volume create -volume <vol_name> -vserver <svm_name> -aggr-list <aggregate name> -aggr-list-multiplier <integer> -size <nn> -anti-ransomware-state enabled -junction-path </path_name>
----
*ARP/AI 상태를 확인하십시오:*

[source, cli]
----
security anti-ransomware volume show
----
--

== SAN 볼륨에서 ARP/AI 활성화

ONTAP 9.17.1 버전부터 SAN 볼륨에서 ARP/AI를 활성화할 수 있습니다. ARP/AI는 활성화 즉시 자동으로 작동하며, link:entropy-eval-period-arpai.html["엔트로피 평가 기간"] 동안 SAN 볼륨을 모니터링하고 보호하는 동시에 워크로드가 ARP/AI에 적합한지 여부를 판단하고 탐지를 위한 최적의 암호화 임계값을 설정합니다.

[role="tabbed-block"]
====
.시스템 관리자
--
. *저장소 > 볼륨*을 선택한 다음 보호하려는 SAN 볼륨을 선택합니다.
. 볼륨 * 개요의 * 보안 * 탭에서 * 상태 * 를 선택하여 비활성화에서 활성화로 전환합니다.
. ARP/AI는 자동으로 평가 기간에 들어갑니다.
. *안티랜섬웨어* 상자에서 ARP/AI 상태 및 평가 상태를 확인하십시오.
+
모든 볼륨의 ARP/AI 상태를 표시하려면 *볼륨* 창에서 *표시/숨기기*를 선택한 다음 *랜섬웨어 방지* 상태가 선택되어 있는지 확인하십시오.



--
.CLI를 참조하십시오
--
*기존 SAN 볼륨에서 ARP/AI를 활성화하는 방법:*

[source, cli]
----
security anti-ransomware volume enable -volume <vol_name> -vserver <svm_name>
----
*ARP/AI가 활성화된 새 SAN 볼륨을 생성합니다.*

[source, cli]
----
volume create -volume <vol_name> -vserver <svm_name> -aggregate <aggr_name> -size <nn> -anti-ransomware-state enabled
----
*ARP/AI 상태 및 평가 상태를 확인하십시오:*

[source, cli]
----
security anti-ransomware volume show
----
 `Block device detection status` 필드를 확인하여 평가 기간 진행 상황을 모니터링하십시오.  `security anti-ransomware volume show`에 대한 자세한 내용은 link:https://docs.netapp.com/us-en/ontap-cli/security-anti-ransomware-volume-show.html["ONTAP 명령 참조입니다"^]을 참조하십시오.

--

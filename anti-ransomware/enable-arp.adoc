= 볼륨에서 ONTAP ARP 활성화
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ONTAP 9.10.1부터 기존 NAS 볼륨에서 자율적 랜섬웨어 방지(ARP)를 활성화하거나 ARP가 활성화된 새 볼륨을 생성할 수 있습니다.


NOTE: ONTAP 9.16.1 이상을 실행 중인 경우 link:enable-arpai.html["볼륨에서 ARP/AI 활성화"]을 참조하십시오.

.이 작업에 대해
NAS 워크로드(ONTAP 9.10.1~9.15.1)에 대한 ARP는 link:learn-about-arp.html#arp-protection-modes["학습 모드"] (`dry-run` 상태에서 시작됩니다. 시스템은 워크로드를 분석하여 정상적인 동작을 파악한 후 위협 탐지를 위한 활성 모드로 전환합니다. 학습 기간이 완료되기 전에 활성 모드로 시작하면 오탐 보고가 과도하게 발생할 수 있습니다.

ONTAP 9.10.1부터 9.12.1까지의 버전에서는 ARP를 학습 모드로 최소 30일 동안 실행하는 것이 좋습니다. ONTAP 9.13.1부터는 ARP가 최적의 학습 기간 간격을 자동으로 결정하고 전환을 자동화하므로 30일 이전에 전환될 수도 있습니다.

ONTAP 9.10.1~9.15.1에서는 SAN 볼륨에서 ARP가 지원되지 않습니다. link:support-arp.html["ARP 지원 구성"]을 참조하십시오.


NOTE: 기존 볼륨에서 학습 및 활성 모드는 볼륨의 기존 데이터가 아닌 새로 기록된 데이터에만 적용됩니다. ARP에 대해 볼륨이 활성화된 후 새 데이터를 기반으로 이전 일반 데이터 트래픽의 특성이 가정되기 때문에 기존 데이터는 스캔되고 분석되지 않습니다.

자율형 랜섬웨어 보호 기능을 활성화한 후에는 환경 및 ONTAP 버전에 따라 전환 기간이 시작될 수 있습니다.

[cols="25,25,50"]
|===
| 볼륨 유형입니다 | ONTAP 버전입니다 | 활성화 후의 동작 


.2+| NAS FlexGroup | ONTAP 9.18.1 이상 | ARP/AI는 학습 기간 없이 즉시 활성화됩니다. 


| ONTAP 9.13.1부터 9.17.1까지 | ARP는 30일 동안 학습 모드로 시작됩니다. 


.2+| NAS FlexVol | ONTAP 9.16.1 이상 | ARP/AI는 학습 기간 없이 즉시 활성화됩니다. 


| ONTAP 9.10.1부터 9.15.1까지 | ARP는 30일 동안 학습 모드로 시작됩니다. 


| SAN 볼륨 | ONTAP 9.17.1 이상 | ARP/AI는 즉시 활성화되어 초기 보수적 임계값에서 전환하기 전에 적절한 경고 임계값을 설정하기 위한 평가 기간을 시작합니다. 
|===
.시작하기 전에
* NFS 또는 SMB(또는 둘 다) 프로토콜이 활성화된 스토리지 VM(SVM)입니다.
* 클라이언트가 구성된 NAS 작업 부하.
* 활동적인link:../concepts/namespaces-junction-points-concept.html["접합 경로"] 볼륨을 위해서.
* 사용하시는 ONTAP 버전에 대한 link:index.html#licenses-for-autonomous-ransomware-protection["올바른 라이센스입니다"].
* (권장) 다중 관리자 검증(MAV)이 활성화되어 있습니다(ONTAP 9.13.1 이상). 보다link:../multi-admin-verify/enable-disable-task.html["다중 관리 검증을 활성화합니다"] .




[[enable-arp-on-nas-flexvol-volumes]]
== NAS FlexVol 볼륨에서 ARP 활성화

System Manager 또는 ONTAP CLI를 사용하여 NAS FlexVol 볼륨에서 ARP를 활성화할 수 있습니다.

[role="tabbed-block"]
====
.시스템 관리자
--
. 스토리지 > 볼륨 * 을 선택한 다음 보호할 볼륨을 선택합니다.
. 볼륨 * 개요의 * 보안 * 탭에서 * 상태 * 를 선택하여 비활성화에서 활성화로 전환합니다.
. *랜섬웨어 방지* 상자에서 *학습 모드에서 활성화*를 선택합니다.
+

NOTE: 학습 모드에서 활성 모드로의 전환을 수동으로 제어하려면 link:enable-default-arp.html["연결된 스토리지 VM에서 자동 학습에서 활성 모드로의 전환을 비활성화합니다."]할 수 있습니다.

+

NOTE: 기존 볼륨에서 학습 및 활성 모드는 볼륨의 기존 데이터가 아닌 새로 기록된 데이터에만 적용됩니다. ARP에 대해 볼륨이 활성화된 후 새 데이터를 기반으로 이전 일반 데이터 트래픽의 특성이 가정되기 때문에 기존 데이터는 스캔되고 분석되지 않습니다.

. *랜섬웨어 방지* 상자에서 볼륨의 ARP 상태를 확인하세요.
+
모든 볼륨에 대한 ARP 상태를 표시하려면 * Volumes * 창에서 * Show/Hide * 를 선택한 다음 * Anti-Ransomware * 상태가 선택되어 있는지 확인합니다.



--
.CLI를 참조하십시오
--
*기존 볼륨에서 ARP 활성화(학습 모드):*

[source, cli]
----
security anti-ransomware volume dry-run -volume <vol_name> -vserver <svm_name>
----
에 대한 자세한 내용은 `security anti-ransomware volume dry-run` link:https://docs.netapp.com/us-en/ontap-cli/security-anti-ransomware-volume-dry-run.html["ONTAP 명령 참조입니다"^]을 참조하십시오.

*ARP가 활성화된(학습 모드) 새 볼륨을 생성합니다.*

[source, cli]
----
volume create -volume <vol_name> -vserver <svm_name> -aggregate <aggr_name> -size <nn> -anti-ransomware-state dry-run -junction-path </path_name>
----
*학습 모드에서 활성 모드로의 자동 전환 비활성화(선택 사항):*

ONTAP 9.13.1부터 9.15.1을 실행 중이고 SVM과 연결된 모든 볼륨의 학습 모드에서 활성 모드로의 전환을 수동으로 제어하려는 경우:

[source, cli]
----
vserver modify <svm_name> -anti-ransomware-auto-switch-from-learning-to-enabled false
----
*ARP 상태 확인:*

[source, cli]
----
security anti-ransomware volume show
----
--
====


[[enable-arp-on-nas-flexgroup-volumes]]
== NAS FlexGroup 볼륨에서 ARP 활성화

ONTAP 9.13.1부터 NAS FlexGroup 볼륨에 대한 ARP 지원이 제공됩니다.


NOTE: FlexGroup 볼륨은 ONTAP 9.13.1~9.17.1에서 ARP/AI가 아닌 학습 모드가 적용된 기존 ARP 모델을 사용합니다. FlexGroup 볼륨에 즉시 활성 모드가 적용된 ARP/AI를 사용하려면 ONTAP 9.18.1이 필요합니다. link:enable-arpai.html["볼륨에서 ARP/AI 활성화"]을 참조하십시오.

[role="tabbed-block"]
====
.시스템 관리자
--
. *저장소 > 볼륨*을 선택한 다음 보호하려는 FlexGroup 볼륨을 선택합니다.
. 볼륨 * 개요의 * 보안 * 탭에서 * 상태 * 를 선택하여 비활성화에서 활성화로 전환합니다.
. *랜섬웨어 방지* 상자에서 *학습 모드에서 활성화*를 선택합니다.
+

NOTE: 학습 모드에서 활성 모드로의 전환을 수동으로 제어하려면 link:enable-default-arp.html["자동 학습에서 활성 모드로의 전환을 비활성화합니다."]할 수 있습니다.

. *랜섬웨어 방지* 상자에서 볼륨의 ARP 상태를 확인하세요.


--
.CLI를 참조하십시오
--
*기존 FlexGroup 볼륨에서 ARP 활성화(학습 모드):*

[source, cli]
----
security anti-ransomware volume dry-run -volume <vol_name> -vserver <svm_name>
----
*ARP가 활성화된(학습 모드) 새 FlexGroup 볼륨 생성:*

[source, cli]
----
volume create -volume <vol_name> -vserver <svm_name> -aggr-list <aggregate name> -aggr-list-multiplier <integer> -size <nn> -anti-ransomware-state dry-run -junction-path </path_name>
----
*ARP 상태 확인:*

[source, cli]
----
security anti-ransomware volume show
----
--
====

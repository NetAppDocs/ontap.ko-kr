= ONTAP System Manager 대시보드에서 클러스터 정보 보기
:hardbreaks:
:toclevels: 1
:allow-uri-read: 
:toclevels: 1

:imagesdir: ./media/


[role="lead"]
System Manager 대시보드를 이용하면 단일 위치에서 ONTAP 클러스터를 빠르고 포괄적으로 확인할 수 있습니다.

System Manager 대시보드에서 중요한 알림, 스토리지 계층 및 볼륨의 효율성과 용량, 클러스터 노드의 상태 및 가용성, 가장 활발한 애플리케이션 및 객체, 성능 지표 등 클러스터 상태, 용량, 네트워크 및 성능에 대한 정보를 확인할 수 있습니다.

ONTAP 9.19.1부터 SVM 관리자는 ONTAP System Manager의 전용 SVM 관리자 대시보드를 사용하여 자체 SVM을 모니터링하고 관리할 수 있습니다. 자세한 내용은 link:task-svm-admin-dashboard-sm.html["System Manager를 사용하여 SVM 관리 및 모니터링"]를 참조하십시오.

대시보드에는 다음과 같이 설명된 4개의 패널이 포함되어 있습니다.



[[view-the-cluster-health]]
== 클러스터 상태 보기

ONTAP System Manager 대시보드의 *Health* 섹션에서 이름, ONTAP 버전, 생성 날짜 등 클러스터에 대한 일반 정보를 확인할 수 있습니다. 또한 클러스터 노드의 전반적인 상태, 클러스터 수준 오류, 경고, 알림 및 클러스터 성능 향상을 위한 권장 수정 사항을 확인할 수 있습니다.

ONTAP 9.20.1부터 클러스터 또는 스토리지 가상 머신(SVM) 인증서 만료 30일 전에 상태 알림이 표시됩니다. 이 알림은 만료까지 남은 일수를 표시하도록 매일 업데이트됩니다. 기본 30일 알림 임계값을 0~90일 사이의 원하는 일수로 수정하거나, 알림을 비활성화하여 표시되지 않도록 하거나, 이미 만료된 인증서에 대한 알림은 표시하지 않고 향후 만료 예정인 인증서에 대한 알림은 계속 받도록 설정할 수 있습니다.

* 클러스터 상태 정보를 보려면 대시보드에서 *Health* 옆에 있는 image:icon_arrow.gif["화살표 아이콘"]를 선택합니다.
* 인증서 만료 설정을 수정하려면 알림을 선택한 다음 *인증서 설정*을 선택하십시오.




[[view-the-cluster-capacity]]
== 클러스터 용량을 확인하십시오

ONTAP System Manager 대시보드의 *Capacity* 섹션에서 클러스터의 스토리지 공간을 확인할 수 있습니다. 사용된 총 논리적 공간, 사용된 총 물리적 공간 및 사용 가능한 디스크 공간을 확인할 수 있습니다.

ActiveIQ에 등록하면 과거 클러스터 데이터를 볼 수 있습니다.

대시보드의 *Capacity* 옆에 있는 image:icon_arrow.gif["화살표 아이콘"] 를 선택하여 총 공간, 사용 공간, 사용 가능 공간 등 클러스터와 관련된 계층의 개요를 포함한 클러스터 용량 정보를 확인합니다. 처리량, IOPS 및 지연 시간에 대한 세부 정보도 표시됩니다. link:./concepts/capacity-measurements.html["ONTAP에서 사용된 스토리지를 보고하는 방법을 알아보십시오."].

용량 보기를 사용하여 로컬 계층 또는 클라우드 계층을 추가할 수 있습니다. 자세한 내용은 을 link:task_admin_monitor_capacity_in_sm.html["클러스터의 용량을 봅니다"]참조하십시오.



[[view-the-cluster-network]]
== 클러스터 네트워크 보기

ONTAP System Manager 대시보드의 *Network* 섹션에서 네트워크에 속한 물리적 포트, 네트워크 인터페이스 및 스토리지 VM을 확인할 수 있습니다.

네트워크 보기에는 네트워크에 연결된 클라이언트 유형이 표시됩니다. 이러한 네트워크에 연결된 각 클라이언트는 숫자로 표시됩니다(예: "NVMe/FC 16"). 각 네트워크 요소에 대한 특정 세부 정보를 보려면 번호를 선택하십시오.

대시보드의 *Network* 옆에 있는 image:icon_arrow.gif["화살표 아이콘"]을(를) 선택하여 포트, 네트워크 인터페이스, 스토리지 VM 및 네트워크상의 호스트를 포함하는 네트워크에 대한 포괄적인 전체 페이지 보기를 확인하십시오.



[[view-the-cluster-performance]]
== 클러스터 성능 보기

ONTAP System Manager 대시보드의 *Performance* 섹션에서 ONTAP 클러스터의 상태와 효율성을 모니터링하는 데 도움이 되는 성능 통계를 확인할 수 있습니다. 이 통계에는 지연 시간, 처리량, IOPS 등 주요 클러스터 성능 지표가 그래프로 표시됩니다.

성능 보기에는 일, 시, 주 또는 연도별로 서로 다른 시간 간격의 성능 통계가 표시됩니다. 다양한 그래프를 사용하여 클러스터 성능을 빠르게 분석하고 최적화가 필요한 특성을 파악할 수 있습니다. 이 빠른 분석을 통해 워크로드를 추가 또는 이동하는 방법을 결정할 수 있습니다. 또한 최대 사용 시간을 살펴보고 잠재적 변경 사항을 계획할 수 있습니다.

성능 보기에는 지연 시간, 처리량 및 IOPS와 관련된 총 성능 메트릭이 표시됩니다.

9.15.1부터 성능 뷰가 향상되어 지연 시간, 처리량, IOPS와 관련된 읽기, 쓰기, 기타 및 총 성능 메트릭에 대한 그래프를 표시할 수 있습니다. 다른 메트릭에는 읽기 또는 쓰기가 아닌 작업이 포함됩니다.

성능 값은 3초마다 새로 고쳐지고 성능 그래프는 15초마다 새로 고쳐집니다. 클러스터 성능에 대한 정보를 사용할 수 없는 경우에는 그래프가 표시되지 않습니다.

시간별, 일별, 주별, 월별 및 연도별 성능 지표를 전체 페이지로 보려면 대시보드의 *Performance* 옆에 있는 image:icon-expansion-arrows.png["확장 아이콘"]를 선택하십시오. 로컬 시스템에 성능 지표 보고서를 다운로드할 수도 있습니다.
